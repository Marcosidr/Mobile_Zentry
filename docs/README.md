# Documentacao do Projeto

Esta pasta concentra os artefatos usados para demonstrar a evolucao do StockFlow na rubrica.

## Arquivos

- `01-contextualizacao.md`: problema, cliente e solucao proposta
- `02-persona.md`: persona principal e necessidades
- `03-requisitos.md`: requisitos funcionais e nao funcionais
- `04-regras-negocio.md`: regras aplicadas pela API e pelo app
- `05-evolucao-produto.md`: roadmap e relacao com commits
