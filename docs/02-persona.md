# Persona

## Carlos Andrade

- Idade: 42 anos
- Papel: proprietario de uma pequena loja
- Contexto: possui cerca de 300 produtos e usa uma planilha para controlar entradas e saidas
- Objetivo: saber rapidamente quais produtos estao acabando e quem realizou alteracoes

## Necessidades

- Consultar quantidade atual de cada produto.
- Identificar produtos abaixo do estoque minimo.
- Permitir que funcionarios registrem entrada e saida.
- Bloquear exclusao de produtos para usuarios comuns.
- Ter imagens para reconhecer produtos com mais facilidade.

## Relacao com perfis

- ADMIN: gerencia produtos, categorias, usuarios, imagens e exclusoes.
- USER: consulta produtos e registra movimentacoes de estoque.
