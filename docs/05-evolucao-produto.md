# Evolucao do Produto

## Versao 0.1

- Estrutura inicial do monorepo.
- API Express com TypeScript.
- Prisma configurado para PostgreSQL.
- Autenticacao JWT.
- Controle de permissao ADMIN e USER.
- CRUD de categorias e produtos.
- Upload de imagem com Multer.
- Registro de movimentacoes de entrada e saida.
- Aplicativo React Native com telas principais.
- Documentacao e diagramas iniciais.

## Proximas versoes

- Tela de usuarios no app mobile.
- Relatorio de produtos com estoque baixo.
- Historico detalhado por produto.
- Exportacao de relatorio.
- Testes automatizados da API.
